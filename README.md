## 🚀 About Me

I'm a Computer Science student and full-stack developer with a strong focus on the backend. I like understanding how things work under the hood, so a lot of my projects rebuild core pieces from scratch: JWT auth without an identity library, a REST API with no framework, and a compiler pipeline from lexer to assembly.

- 🔭 **Building:** RESTful APIs, secure auth flows, full-stack web apps, and database-driven platforms
- 🏗️ **Interested in:** software architecture, scalable backend services, and system design
- 🧩 **Also work with:** low-code solutions on Oracle APEX
- 🌐 **More about me:** [mostafa-portfolio-kappa.vercel.app](https://mostafa-portfolio-kappa.vercel.app/)
